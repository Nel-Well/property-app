# Property Portal Web App

Responsive React/Vite marketplace experience for the Property Portal.

## Local setup

```bash
npm install
cp .env.example .env
npm run dev
```

The app runs at `http://localhost:5173`. If the API is unavailable, it falls back to a small local demo dataset so the visual experience remains reviewable.

The repository is configured for shadcn/ui with preset `b7ClNFsdU`; the first UI primitives live in `components/ui`.
